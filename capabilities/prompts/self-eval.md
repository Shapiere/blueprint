Self-evaluation of this repository:

Assess five dimensions with repository evidence (read files; quote facts — never vibes):
1. **Capability quality** — from `capabilities/index.md`: active vs installed ratio, validations current, any stale `last-verified`.
2. **Workflow effectiveness** — from templates/skills and recent sessions: do documented workflows get used? any overlap?
3. **Governance compliance** — capture loop adherence (CHANGELOG/DECISIONS currency), decision-log completeness.
4. **Architecture compliance** — registry and structure match `docs/ARCHITECTURE.md`; no new folders/layers without decisions.
5. **Repository health** — automated scan results (broken links, orphans), git cleanliness, TODOs backlog size.

Then output: per-dimension verdict (PASS / WARN / FAIL) with one evidence link each, a list of recommended improvements ranked by value, and a single summary verdict. Record the recommendation in the session's DECISIONS entry when actionable.
